#### What is it?
- 2D cellular automata with 32 possible states per cell
- Also a Turing Machine
- Capable of creating anything that you can encode within its description
#### 3 Parts
- The Description
	- Tape encoding the information needed to create a new machine
	- Similar to DNA encoding an organism
- Universal Constructor
	- Reads the blueprint and create the machine that is encoded within it
	- Robotic arm building structures
- Universal Copier
	- Copies the blueprint into the new machine
	- Continue the cycle of self-replication

#### Evolution
- Mutations in the blueprint copying can be introduced that lead to natural selection and evolution
	- Fit machines are able to create more copies of themselves
	- Fitness function is the ability to self-replicate
