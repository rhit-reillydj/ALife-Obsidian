### Gene Regulation in Biology
- Gene Regulatory Network (GRN)
	- Set of DNA segments before or near a gene that describe how it should be expressed
		- Produces proteins according to this description
	- These sets can encode to promote, weaken, or silence the genes that follow
	- This can effectively turn on or off a gene or set of genes

### Artificial Gene Regulatory Networks (AGRN)
- Simulating a gene network exactly is computationally intense
- Compromise with an opaque thought experiment
- Differential equation model 
	- Describe continuous change in protein concentrations
- Boolean networks
	- Genes are on or off
- Feedback loops
	- Simple positive/negative feedback loops can lead to oscillators

### Evolution
- Can encode genomes indirectly
	- Bit string 01011001
- Attempt to reproduce some target function such as oscillatory, sigmoid, or exponential
- Very robust
	- Mutation will likely still produce a fit offspring
	- Maintain functionality with gene duplication or crossover

### Applications
- Can be used to control cell division to try to achieve a final state from all of the cells
	- French flag
	- Salamander
- Robotics control
	- Input proteins, output proteins
	- Successfully pole-balanced, maze-navigated, and won a simulated car racing championship
